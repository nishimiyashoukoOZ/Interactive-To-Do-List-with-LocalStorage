# Interncircle To-do List

A lightweight, responsive to-do list built with HTML, CSS, and vanilla JavaScript. No installation or build step is required.

## Run

Open `index.html` in a web browser.

## Features

- Add, complete, and delete tasks
- Filter tasks by all, to do, or done
- Clear completed tasks
- Save tasks in browser `localStorage`
- Show the current date and task progress

Tasks are stored in the current browser on this device; they are not synced to a server.
